# Agents

Specialized agents for analyzing, grading, and comparing content within the myk-skills ecosystem.

## analyzer

Performs deep analysis of code, text, or structure against defined criteria.

**When to use**: When the user asks to "analyze", "review", or "examine" quality, structure, or correctness.

## grader

Scores or evaluates quality against criteria rubrics.

**When to use**: When the user asks to "grade", "score", or evaluate against a rubric.

## comparator

Compares two or more items against each other.

**When to use**: When the user asks to "compare", "contrast", or identify differences between items.
